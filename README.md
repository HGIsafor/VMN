# VN-N

Combined voice memos and notes.

## App frame

This repository now includes a lightweight app frame for a combined Notes + Voice Memos experience where every memo is saved with a tied note.

### Core flow

- Create a new memo with:
  - a title
  - an optional audio clip
  - a required note
- Save as one memo-note pair
- View saved pairs in a single timeline list

## Run locally

```bash
npm install
npm test
npm start
```

Then open `http://localhost:4173/index.html`.
